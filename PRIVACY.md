# 🔒 Privacy Policy — NORA TUNNEL

## Local-First Privacy Model

Nora Tunnel is designed with a **local-first privacy model**. By default:

- **Configurations** → Stored locally on device
- **Profiles** → Stored locally in encrypted database
- **Connection History** → Stored locally only
- **Logs** → Stored locally, auto-rotated
- **Credentials** → Stored in Android Keystore-backed secure storage

## No Remote Account Required

No remote account, registration, or login is required for basic VPN/tunnel functionality.

## Data Collection

Nora Tunnel does **NOT**:

- Collect personal data
- Upload configurations to remote servers
- Include hidden telemetry
- Track usage patterns
- Record browsing history
- Share data with third parties
- Include credential harvesting
- Serve advertisements

## Analytics

If analytics are ever added in the future, they will be:
- **Explicit** — Clear notice to the user
- **Opt-in** — Disabled by default
- **Minimal** — Only essential crash/usage data
- **Transparent** — Fully documented

## DNS

DNS queries are routed through the configured tunnel when connected. Nora Tunnel does not:
- Intercept DNS when not connected
- Log DNS queries permanently
- Redirect DNS to third-party resolvers without user configuration

## Third-Party Libraries

Nora Tunnel uses well-maintained upstream libraries. Each library's privacy practices are governed by their own policies.
